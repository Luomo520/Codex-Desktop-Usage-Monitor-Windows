# Codex Usage Monitor 3.1.3

本文件是 `v3.1.3` 的 GitHub Release 说明草稿。当前仅用于本地发布准备，尚未创建远程标签或 Release。

## 主要更新

- 新增 CC Switch 当前 Codex 供应商联动，只读复用余额脚本、Token 汇总与最近请求信息，并在切换供应商后自动跟随。
- CC Switch 的“今日 Token”固定以百万 Token 的 `M` 为单位显示，例如 `12,340,000` 显示为 `12.34M`。
- 新增最近 X 次回答缓存命中率明细，X 可设置为 1–20，折叠栏显示最近 X 次有效记录的算术平均值。
- 新增缓存低命中率标红阈值，默认 90%，范围 0–100；设置为 0 可关闭，只有严格低于阈值才标红。
- 折叠监视栏优先放置到当前会话标题栏右侧，并保留原输入框工具栏回退定位。
- 补充中英文文案、设置持久化、日志恢复、CC Switch 安全边界及界面生命周期测试。

## 安装

1. 下载 `codex-usage-monitor-windows-3.1.3.zip`。
2. 解压后在 PowerShell 中运行：

   ```powershell
   pwsh -NoProfile -File .\install.ps1
   ```

3. 正常退出当前 Codex，再通过桌面快捷方式 `Codex Usage Monitor` 启动。
